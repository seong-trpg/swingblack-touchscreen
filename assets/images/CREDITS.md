# 이미지·폰트·라이브러리 출처

## 이미지

지금 앱에 들어 있는 그림은 모두 이 프로젝트에서 직접 그린 SVG 일러스트다(`js/illust.js`, `js/intro.js`). 외부 프리 소스 사진은 쓰지 않았다.

프리 소스 사진을 임시로 쓰게 되면 아래 표에 기록한다.

## 아이콘

앱 아이콘(`assets/icons/`)은 `tools/make-icons.py`로 만든 임시 모노그램이다. 로고 원본이 오면 로고로 다시 만든다.
